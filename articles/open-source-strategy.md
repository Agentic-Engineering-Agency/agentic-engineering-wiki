# Open source strategy

## Why we open-source

**Primary effect today:** **indirect credibility and inbound interest** — not yet a **closed-deal attribution channel** (founder-confirmed 2026-06-26).

Public positioning: "We work in the open" ([agency site](../external-sources/agenticengineering-agency-site.md)).

## Portfolio reality

GitHub org has **21 public repos** (as of 2026-06-26). Multiple overlapping **agent harness** experiments exist:

| Repo | Stated purpose |
| --- | --- |
| [SpecSafe](https://github.com/Agentic-Engineering-Agency/specsafe) | TDD framework for AI-assisted development |
| [ultimate-harness](https://github.com/Agentic-Engineering-Agency/ultimate-harness) | Portable discipline across coding agents |
| [omp-pantheon](https://github.com/Agentic-Engineering-Agency/omp-pantheon) | OMP-based agentic harness + SpecSafe + Honcho + EvalFly |
| [pi-seshat](https://github.com/Agentic-Engineering-Agency/pi-seshat) | Pi coding-agent harness + Honcho + SpecSafe |
| [agentforge](https://github.com/Agentic-Engineering-Agency/agentforge) | Self-hosted agent framework (Mastra + Convex) |

> [!IMPORTANT]
> **Internal assessment:** some repos are **abandoned experiments** — **consolidation/cull needed**. Maintenance tax is real for a 2-person team.

## SpecSafe

**Decided (R3 28B):** [methodology — open core forever](./specsafe-product-thesis.md); agency differentiator, **not** commercial product.

Public claim: 8 tools, 3 integration tiers ([agency site](../external-sources/agenticengineering-agency-site.md)).

## Operating rules (draft)

1. **No new harness repo** without archiving or merging an existing one.
2. **One "golden path" repo** for external contributors — **[decision OPEN](./oss-golden-path-decision.md)** (founder: not picked yet).
3. Track inbound leads from GitHub; if no attribution in 6 months, cut inactive repos.
